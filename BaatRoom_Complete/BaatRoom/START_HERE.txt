BAATROOM — START HERE

1. Extract the ZIP. Open the extracted BaatRoom folder in Windows VS Code.
   app.py and requirements.txt must be visible in that folder.

2. Install Python 3.11 or newer if needed. Python 3.12 is recommended.
   In VS Code choose Terminal > New Terminal. Run EACH command separately:

python --version

python -m venv .venv

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

.\.venv\Scripts\python.exe app.py

3. Open http://127.0.0.1:5000 in your browser. Pick any nickname and chat.
   No login, email, paid API key, Node.js or database setup is required.
   Once your virtual environment is activated, the start command is simply:

python app.py

4. Try a second browser or an incognito window for a different guest.
   Extra tabs in the SAME browser share one guest identity and count once.

5. Use the LED theme swatches on desktop, or the sparkle button on mobile.
   Ember / Aurora / Ultraviolet / Arctic. LED glow can be switched off.

6. Stop the server with Ctrl+C. Ordinary chat history clears on restart.
   The reports SQLite database is created automatically in instance/.

OWNER MODERATION (optional locally, required when deploying publicly)

Copy the example settings:

Copy-Item .env.example .env

Generate a random value. Run this twice, saving DIFFERENT outputs in .env
as SECRET_KEY and OWNER_SECRET. Keep both private.

python -c "import secrets; print(secrets.token_hex(32))"

Restart the server. In a SECOND terminal, review received reports:

.\.venv\Scripts\python.exe app.py owner reports

More owner commands and public deployment instructions are in README.md.

SHARE IT ON INSTAGRAM / WITH FRIENDS

http://127.0.0.1:5000 is only your own computer. Friends cannot use that URL.
Publish this Python app on an HTTPS web host that supports WebSockets.
README.md includes Render setup, a production command and all settings.
After publishing, set PUBLIC_URL to the real HTTPS origin and redeploy.
Then Invite Friends shares that public chat link directly.

The supplied ZIP is not a public deployment. Visitors pay nothing to use
the app; the owner may have hosting costs or free-tier usage limits.

TROUBLESHOOTING

Missing module? Run the install command above using the SAME .venv Python.
Do not double-click app.py or open chat.html directly.

Port 5000 occupied? In PowerShell, run these separately:

$env:PORT="5001"

.\.venv\Scripts\python.exe app.py

Then open http://127.0.0.1:5001.

If you set PUBLIC_URL to an HTTPS host, local HTTP is no longer that origin.
For local development, use APP_ENV=development, PUBLIC_URL blank,
COOKIE_SECURE=false and TRUST_PROXY_COUNT=0 in .env, then restart.

Never share .env, reports.sqlite3, cookies, or your owner secret.
